This repository contains the scripts and corpus files used to calculate entropy measures (including naïve entropy, relative entropy, and Zhang's entropy) for both raw and tagged texts of university names in China and the United States.

To compute these measures, users can run the provided Python scripts after modifying the path parameters to match the locations of the USraw, UStag, CNraw, and CNtag files on their local machines.

The document entitled "Tagging Scheme" provides a detailed description of the coding conventions and annotation schemes used in the tagged corpus files.
